# Texte de démonstration

`verne_tour_du_monde.txt` contient les chapitres I à XV du roman *Le Tour du monde en quatre-vingts jours* de Jules Verne (1873), dans l'édition numérique du Projet Gutenberg (eBook n° 800) : <https://www.gutenberg.org/ebooks/800>

Jules Verne est mort en 1905 : son œuvre est dans le domaine public. Conformément à la licence du Projet Gutenberg, l'en-tête et la licence du fichier d'origine ont été retirés ; seul le texte du roman est conservé.

C'est la même démarche que le jeu de données « Tiny Shakespeare » utilisé par `nanoGPT` pour entraîner un petit modèle caractère par caractère, appliquée à un roman français.

Modifications apportées :

- seuls les chapitres I à XV sont conservés (environ 154 000 caractères) ;
- les numéros et titres de chapitres en majuscules sont retirés ;
